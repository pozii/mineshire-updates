# Mineshire updates

Installers and update lists for [Mineshire](https://mineshire.com), a launcher that sets up Minecraft servers on your own computer.

This repository only holds releases. Download the newest installer from the [site](https://mineshire.com/downloads) or the [Releases](../../releases) page.
